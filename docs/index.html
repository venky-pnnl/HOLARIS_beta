Compare measurements from the same experiment.

HOLARIS pairs instrument data with workflow events and stage readbacks. You can trace when a measurement was made, what the instruments were doing, and which condition the measurement belongs to.

Set the experimental conditions

Define the order of motion and acquisition steps, record operator checkpoints, and use actual position readings to track when a stage reached its target.

Compare the sample response

Use phase images to follow spatial change, hyperspectral scans to locate wavelength-dependent features, and Raman spectra to examine vibrational bands.

How the apps connect to the data

Start with the workflow records to find the relevant steps. Align the interferometer’s camera timestamps with the magnet-stage encoder readbacks to see how the optical response relates to measured motion. Raman spectra and hyperspectral scans add complementary spectral information.

ApplicationDataset recordsWhat you can examine
Command Center Workflow steps, event timestamps, and acquisition metadata Identify which measurements belong to each step and reconstruct the sequence.
Motion Control Magnet-stage encoder readbacks Locate when the stage moved, reached position, and retracted.
mMZI Native interferogram stacks, reference frames, wrapped phase maps, and camera timestamps Align the phase response to the measured magnet motion.
Spectra Forge Raman kinetic-series spectra before approach, at the cuvette, and after retraction Compare vibrational bands across the three magnet positions.
HyperspectralCam White-light transmission scans and He–Cd-excited Dy³⁺ emission scans Examine spatial variation in transmission and in dysprosium emission.
